# 巡码接入、巡检与修复改进

依据：用户 2026-10-13 的八项修改要求。保持 Python 标准库、SQLite、本机网页。

## 操作与说明

移除宣传标题、英文口号、重复说明。接入按钮调用受会话令牌保护的本机文件夹选择接口，取消后不接入；项目名称取文件夹名，完整路径折叠显示。附加约定保存在项目根目录 `CODESCOUT_RULES.md`，通过网页编辑或直接编辑此文件均会触发检查；AGENTS.md、CLAUDE.md 不再默认充当巡码约定来源。保存必须核对原文，避免覆盖并发编辑。

## 检查

新建 context.py 规划按文件/行段分批的检查输入。每次请求最多 12000 字符且不超过用户预算，最多一个主检查文件与按关键词找到的少量关联片段；规范内容计入预算。大文件按行段分割，保留真实行号。所有批次分别校验证据，保存已完成批次和覆盖行段；相同快照/配置失败重试或重启可继续。变化或约定变化使旧任务失效，未完成范围不可伪装通过。

添加 Python AST 语法检查与符号索引，用于确定性定位语法问题及相关调用/文档搜索；其他语言保持文本片段检查，明确验证范围。

## 修复

用户对单条问题选择生成修复。Agent 通过受范围和预算限制的 read_file/search 工具读取当前快照，返回修改片段；后台实际核对路径、源片段、Python 语法并生成 diff。修复方案和源哈希持久化，预览阶段不改源码。用户点击应用后先核对全部源文件和当前许可，再在授权文件内原子替换；失败记录已应用范围，冲突不覆盖用户编辑。备份保存在本机修复记录目录。

应用后校验实际文件；支持用户在项目设置中明确配置测试命令，以 shell=False 在项目目录执行并保存有限输出、退出码和超时。未配置命令只报告语法校验，不能宣称项目测试通过。安排自动复查，验证状态与问题是否解决分别展示。不创建提交、推送或合并。

## 界面和启动

保持已打开的路径、覆盖范围和修复 diff 详情，轮询不改变用户展开状态。显示批次/文件进度及未完成原因。start.bat 检测 Python 3.11+，切换到脚本目录并启动服务/浏览器；启动失败保留窗口并显示原因。另提供根工作区 BAT 入口，便于直接双击。

## 验证

真实临时项目和模型 HTTP 替身覆盖分批、长文件、上下文硬上限、恢复、约定并发编辑、修复生成/应用/冲突/验证失败。浏览器验证详情在多轮刷新后保持打开、简化文案与项目显示。Windows 选择器的调用、取消和错误通过边界测试；真实选择对话框需在本机可交互环境操作。真实模型质量仍需用户模型和标注样例评估。
