# 巡码（CodeScout）

通过本地后台服务和浏览器界面，自动检查项目代码、注释、文档与用户约定的偏差。

当前为 **v0.1 本地预览版**：已实现项目接入、外部模型配置、首次自动检查、工作目录变化后的自动复查及报告查看。这是路线图阶段 1 和阶段 2 的一部分，**尚非完整第一版**；本地提交快照、未拉取的远程提交监控和 Agent 修复仍待实现。

## 启动

需要 Python 3.11 或更高版本。运行时只使用标准库，无须安装第三方依赖。当前已在 Windows / Python 3.11 验证。

在本 README 所在的 `mobileyun_project` 文件夹运行：

```powershell
python -m codescout
```

打开启动时显示的完整本机链接，例如 `http://127.0.0.1:8765/#token=...`。链接中的令牌用于访问当前服务会话；重启服务后使用新链接。默认只监听 `127.0.0.1`。

端口已占用或希望指定保存目录时：

```powershell
python -m codescout --port 8766 --data-dir .codescout/local
```

默认配置、模型密钥、检查快照和报告保存于 `%LOCALAPPDATA%\CodeScout\state.db`。密钥保存在本机数据库中，不通过 API 返回给网页；数据库还包含被检查的项目文本，请放在仅本人可访问的目录。此预览版尚未接入系统凭据保险库。

关闭网页后服务继续工作；关闭运行服务的终端或按 Ctrl+C 会停止后台检查。目前没有安装为系统服务或开机启动。

## 使用

1. 点击“模型设置”，填写兼容 Chat Completions 的 API 基础地址、模型名称和密钥。基础地址填到 `/v1` 等协议前缀，服务会附加 `/chat/completions`；外部地址使用 HTTPS。本机测试服务支持 HTTP。密钥留空时保留原密钥。
2. 接入本地项目的绝对文件夹路径，配置排除项和附加约定，明确允许必要代码发送到该模型。
3. 后台自动读取快照内的 `AGENTS.md`、`CLAUDE.md` 及文本文件，执行首次检查。
4. 查看问题的位置、源码证据、关联文档、约定、建议和置信度；可标记忽略或恢复待处理。
5. 保存项目文件后，后台自动复查。约定和排除项可通过“项目设置”修改；模型配置变化也会触发新检查。

支持暂停、恢复和重新检查。移除项目监控及本机报告不会删除项目源文件。此版本只报告问题，不执行修复命令或修改源文件。

## 覆盖范围与失败处理

- 每 2 秒核对工作目录，在观察到稳定快照 1 秒后安排检查；相同快照和配置去重，模型请求串行执行。
- Git 项目遵循 Git 忽略规则，包含未跟踪的有效文件；无 Git 文件夹可直接接入。当前 Git 分支/HEAD 仅为工作目录快照的元数据，不代表已完成独立提交审计。
- 默认排除 Git 元数据、依赖及构建目录、常见凭据文件、本机数据库、二进制和链接文件/目录。文件名过滤不能识别所有凭据；接入前配置项目实际排除范围。
- 单文件不超过 256 KiB，快照不超过 8 MiB / 2000 个文件，仅支持 UTF-8 文本；超限或不支持的内容会记录原因。
- 默认模型输入预算为 60000 字符。优先读取约定、变化文件和文档，逐文件完整加入；无法容纳的文件列为未覆盖，结果为部分完成。没有分批检查、语言解析器或依赖图分析。
- 模型返回的问题必须引用已提供的文件、真实行号和源码引文。无效输出、限流、超时或连接失败显示检查失败，不视为“无问题”。
- 失败后按 5、30、120 秒最多自动重试 3 次；用完后保留失败状态，可修正配置或手动重新检查。观察位置和成功基线分别记录，失败不会丢掉待检查变化。
- 新快照、排除项或模型配置出现时，旧报告标记过期；部分检查和过期任务不会自动解决旧问题。重启后重新核对，运行中断的检查保留失败记录。

模型依据自然语言约定进行检查；不会证明程序完全正确。真实语义准确度仍需使用实际服务与人工标注样例评估，当前测试服务用于验证流程与协议。

## 开发与验证

```powershell
python -m unittest discover -v
node --check codescout/web/app.js
```

Node.js 只用于可选的网页脚本语法检查，运行产品不需要 Node.js。测试使用临时目录和本机模型替身，不调用收费模型。若运行环境限制本机 HTTP 连接，需允许测试进程访问回环地址。

模块职责：`snapshot.py` 固定检查内容，`store.py` 保存状态，`model.py` 适配外部协议，`checker.py` 构造上下文与校验证据，`service.py` 观察与调度，`server.py` 提供本机 API，`web/` 为中文管理界面。
